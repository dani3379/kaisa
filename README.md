# kaisa

## Live preview

[Open the Kaisa Chess Club website](https://dani3379.github.io/kaisa/)

This is the existing English static-site version, published from the root of `main` with GitHub Pages. The recovered Bulgarian multipage version is a separate archive and has not replaced this site.

Membership controls, social links and contact details include demonstration placeholders. The legacy `admin/` configuration depends on a separate CMS backend and is not enabled by GitHub Pages.

The News, About Us and Tournaments cards include locally hosted chess photography, with source and license information in [CREDITS.md](CREDITS.md). The layout adapts to small screens; the main navigation links to the corresponding page sections.
